## 1. 背景与目标

### 1.1 背景

量化模块是本产品认知门槛最高的功能区。以当前线上两个核心页面为例：

**「个股量化」页**（自定义 / 智能量化双 Tab、股票设定、自选股热门回测、热门股一键回测）在首屏就要求用户同时理解三件事——选哪只股票、用哪种策略、「回测」到底算的是什么。而页面本身只给了字段名，没有给因果关系：用户看到「回测收益（近 7 天模拟）25.50%」和「进取型 策略风格」，无法判断这个数字是历史模拟还是预期收益、也不知道「立即回测」点下去会发生什么。

**「策略详情」页**信息密度更高，一屏内并列了策略收益（模拟）、今日收益、平均胜率、盈亏比、最大回撤五个指标，向下还有收益走势对比图、时间区间切换、当前持仓（模拟）/ 交易明细（模拟）、策略逻辑说明中的选股因子（换手率、连涨天数、日量比）以及底部主 CTA「复制策略选股因子」。其中至少三处存在**结构性误读风险**：

1. **正收益 + 全绿持仓的矛盾**：页面上方「策略收益（模拟）3.78%」为正，下方「当前持仓（模拟）」五只标的持仓盈亏却全为负数。二者口径不同（累计收益含已平仓交易，持仓盈亏只是在持标的的浮动盈亏），但页面未作任何说明，用户会直接怀疑数据造假。
2. **「今日收益」显示为 `--`**：非交易时段或未结算时的空值没有解释，容易被理解为异常。
3. **「复制策略选股因子」是全页唯一主 CTA，但用户不知道复制到哪里去了**——它实际指向「个股量化 - 自定义」的参数区，是两个页面之间唯一的闭环动作，而这个闭环当前完全靠用户自己猜。

同时，本模块的用户构成中**存量用户占多数**，他们已经形成使用习惯。这决定了引导方案的基本约束：**不能为了教会新用户而打扰老用户**。

### 1.2 目标

用「不打断、可忽略、可重看」的轻引导，把两个页面的关键因果关系与易误读指标解释清楚。

| 类型 | 目标 | 首期衡量指标 |
| --- | --- | --- |
| 用户目标 | 新用户能独立完成一次回测 | 新手首次「立即回测」完成率相对对照组 **+10 pp** |
| 用户目标 | 理解页面数据口径 | 术语点释点击率 ≥ **5%**；「看不懂 / 数据有问题」类反馈工单下降 **20%** |
| 业务目标 | 打通两页闭环 | 策略详情页「复制策略选股因子」点击率相对对照组 **+15%** |
| 业务目标 | 提升深度浏览 | 策略详情页滚动到「策略逻辑说明」的比例 **+8 pp** |
| 体验目标 | **引导本身不构成打扰** | L1 提示手动关闭率 ≤ **15%**；引导曝光后 3s 内退出页面的比例不高于对照组 **+0.5 pp**；引导相关负反馈率 ≤ **0.3%** |
| 合规目标 | 引导文案不产生收益暗示 | 全量文案过合规评审，模拟标识 100% 常驻 |

### 1.3 非目标（本期明确不做）

用户诉求明确要求「不要特别强的那种引导」，以下形态本期一律不做，且写入设计红线：

1. **不做全屏蒙层多步教学**（挖孔高亮 + 下一步 / 上一步 + 步骤条 1/5），也不做任何形式的强制走完；
2. **不做拦截点击的引导**——所有引导层不吞事件，用户点到目标元素即正常执行原有功能，引导自行消失；
3. **不做开屏弹窗、不做居中模态、不做全屏视频教程页**；
4. **不做手指动画 / 连续动效牵引**，不做遮罩内嵌套多个高亮点；
5. **不给引导加红点与角标**（红点是消息机制，不是教学机制，滥用会污染全局未读体系）；
6. 不做视频、不做图文长教程的强制前置；帮助内容只作为**用户主动查询**的兜底（见 4.5）；
7. 不改动两个页面既有的信息架构、字段口径与交互逻辑，引导只做**解释层**；
8. 不做个性化引导选择（V1.2 评估）、不做 Web 端（V1.1 跟进）。

## 2. 引导强度分级模型

### 2.1 四条原则

本方案所有引导必须同时满足：

| 原则 | 具体含义 | 可验证判据 |
| --- | --- | --- |
| **不打断** | 不遮挡用户当前正在看的内容，不拦截点击，不阻塞任何原有操作路径 | 引导层 `hitTest` 全透传；引导存在时页面所有功能可正常触达 |
| **可忽略** | 用户完全不理会时，引导会自己消失，且不影响任务完成 | 无「必须点确认才能继续」的形态；自动消失有明确条件 |
| **可重看** | 消失后用户能主动找回，不依赖「清缓存重装」 | 常驻帮助入口 + 术语点释常驻 |
| **一次只教一件事** | 单条引导只承载一个信息点，同屏不叠加 | 同一时刻屏幕上最多 1 条自动引导 |

### 2.2 L0~L3 强度分级

| 级别 | 名称 | 形态 | 是否遮挡 | 是否拦截点击 | 消失方式 | 打扰度 | 本期 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **L0** | 常驻自解释 | 行内副标题、字段后缀、虚线术语、脚注、空态文案 | 否（属于页面内容） | 否 | 不消失 | 0 | ✅ 全量 |
| **L1** | 单句轻提示 | 顶部通栏细提示条 / 元素旁小气泡，单行文案 | 否（顶部条挤压布局，不压内容） | 否 | 停留超时 / 滚动 / 用户操作 / 点关闭 | 低 | ✅ 2 页共 4 条 |
| **L2** | 局部聚焦 | 目标元素描边高亮 + 单气泡，**无全屏遮罩** | 否 | 否（点穿透，直接执行原功能） | 点击任意处 / 超时 / 滚动 | 中低 | ✅ 2 页共 2 条 |
| **L3** | 全屏分步教学 | 全屏蒙层挖孔 + 步骤条 + 下一步按钮 | 是 | 是 | 必须走完或点跳过 | 高 | ❌ 不做 |

### 2.3 为什么上限定在 L2

L3 的收益集中在「一次性把功能讲全」，代价是**在用户还没有使用意图时强行占用注意力**。对本模块尤其不划算：

- 量化模块的核心成本不是「找不到按钮」，而是「看不懂数字」。L3 擅长解决前者，L0 的术语点释才解决后者——用 L3 讲口径，用户当场记不住，回到页面依然要重新查；
- 页面存量用户占多数，L3 无法做到只对新手无损（判定必然有误差），一次误伤的体验成本远高于一次教学收益；
- 两个页面的关键动作（「立即回测」「复制策略选股因子」）都是明确的大号主按钮，本身不存在发现性问题，只存在「点了会怎样」的预期问题——L2 的一句气泡足够。

因此本期结论：**用 L0 承载理解成本（长期有效），用 L1/L2 承载预期建立（一次性），完全放弃 L3。** 需要更强引导的用户由常驻帮助入口自助获取（拉动式，而非推送式）。

### 2.4 引导编号规则

`guide_id` 形如 `G-<页面码><级别><序号>`，`priority` 为四位整数，数值越小越先展示，由服务端配置下发，**客户端不硬编码**。

```
页面码：Q = 个股量化页，D = 策略详情页
号段：1000~1999 个股量化页，2000~2999 策略详情页
段内：x100~x199 为 L1，x200~x299 为 L2（L0 属页面内容，不参与编排，不占号段）
```

## 3. 用户分层与触发前提

### 3.1 新手判定

`is_novice` 由服务端计算并随页面首屏接口下发，客户端不自行判断（避免多端口径不一致）。满足任一即为新手：

1. 从未完成过任意一次回测（`backtest_completed_count = 0`）；
2. 注册时间 ≤ 7 天且量化模块访问次数 ≤ 3；
3. 近 90 天未进入过量化模块（回流用户，视为需要重新建立预期）。

### 3.2 老用户保护

以下用户**不触发任何 L1 / L2 自动引导**，仅保留 L0 与帮助入口：

- 已完成 ≥ 1 次回测，或已点击过 ≥ 1 次「复制策略选股因子」；
- 已在设置中关闭「功能引导提示」；
- 历史上被熔断（见 6.4）；
- 当前处于其他强流程中（新股申购、开户、风测、支付、活动弹窗等已占用注意力的场景）。

### 3.3 全局前置条件

自动引导（L1 / L2）展示需同时满足：

1. 页面首屏关键数据已加载成功且渲染完成（骨架屏、loading、错误态、空态一律不出引导）；
2. 引导目标元素在当前视口内可见面积 ≥ 80%，且位置稳定 ≥ 500ms（避免列表回流导致气泡指错）；
3. 当前无其他浮层（弹窗、Toast、半屏、键盘、下拉刷新中）；
4. 引导配置已从服务端拉取成功（拉取失败即静默跳过，不使用兜底默认值弹引导）；
5. 未超过频控与编排规则（见第 6 章）。

| 「股票设定 - 请选择」 | 必须选吗？不选能不能用？ | L0 空态文案 + L2 聚焦 |
| 「自选股热门回测」卡片 | 这些股票是推荐吗？ | L0 区块说明 |
| 「回测收益（近 7 天模拟）25.50%」 | 是历史还是预测？我能拿到吗？ | L0 术语点释 |

| 「热门股一键回测」148.76% | 为什么比自选股高这么多？ | L0 区块说明 |

### 4.2 L0 常驻自解释（无打扰，长期有效）

| 编号 | 位置 | 形态 | 文案 |
| --- | --- | --- | --- |
| Q-L0-1 | 页面标题下 / Tab 区下方 | 行内浅色说明（1 行，可随滚动上移） | 「用历史行情模拟策略表现，不产生真实交易」 |
| Q-L0-2 | 「股票设定 - 请选择」下方（仅未选股票时） | 空态浅色提示 | 「未选股票时，下方展示热门标的的模拟示例」 |
| Q-L0-3 | 「自选股热门回测」区块标题右侧 | `?` 小图标 → 点开气泡 | 「按你的自选股跑出的模拟结果，按收益排序，非投资推荐」 |
| Q-L0-4 | 「热门股一键回测」区块标题右侧 | `?` 小图标 → 点开气泡 | 「近期关注度高的标的，样本区间可能与自选股不同，收益不可直接横向比较」 |
| Q-L0-5 | 「回测收益（近 7 天模拟）」文案 | 虚线下划线 → 点释气泡 | 见附录 C 词条 `T-BACKTEST-RET` |
| Q-L0-6 | 「策略风格：进取型 / 稳健型」 | 虚线下划线 → 点释气泡 | 见附录 C 词条 `T-STYLE` |

> Q-L0-3 / Q-L0-4 是本页最容易被忽略但性价比最高的一项：它同时回答了「这是不是推荐」（合规）与「为什么两个区块收益差 6 倍」（信任）。

### 4.3 L1 单句轻提示

| guide_id | priority | 触发时机 | 形态与位置 | 文案（≤ 20 字） | 消失条件 | 展示上限 |
| --- | --- | --- | --- | --- | --- | --- |
| `G-Q-L1-01` | 1100 | 新手**首次**进入本页，首屏渲染完成后 800ms | 顶部通栏细提示条（挤压布局，不覆盖内容），高 36pt | 「选股票 → 选策略 → 看模拟表现，不会真实下单」 | 停留 6s 自动收起 / 滚动 ≥ 半屏 / 点任意功能 / 点右侧 `×` | 终身 1 次 |
| `G-Q-L1-02` | 1110 | 新手**首次**切到「智能量化」Tab 时 | Tab 下方小气泡（箭头指向 Tab） | 「自动跑一遍全部策略，约需 10 秒」 | 停留 5s / 任意点击 | 终身 1 次 |

`G-Q-L1-01` 与 `G-Q-L1-02` 不同屏共存：切 Tab 时若 `G-Q-L1-01` 仍在，先收起再排队 300ms 后出气泡（同会话内两条已达全局上限，实际会命中 6.2 规则被跳过，仅在跨会话时出现）。

### 4.4 L2 局部聚焦

| guide_id | priority | 触发时机 | 形态 | 文案（≤ 24 字） | 消失条件 | 展示上限 |
| --- | --- | --- | --- | --- | --- | --- |
| `G-Q-L2-01` | 1200 | 新手在本页**停留 ≥ 8s 且未做任何有效操作**，且当前未选股票 | 「股票设定」行 1pt 主色描边 + 上方单气泡，**无全屏遮罩**，不拦截点击 | 「先在这里选一只股票，回测更贴近你自己的持仓」 | 点击任意处 / 8s 超时 / 滚动 | 终身 1 次 |

三条硬约束：

1. **必须以「停留且无操作」为触发条件，不能进页面就弹**——用户自己会点的时候不要教；
2. 描边使用静态样式或单次 600ms 呼吸，**不做循环动效**；
3. 气泡出现时「股票设定」行仍可直接点击，点击后气泡立即消失并正常跳转选股页，该次记为 `guide_target_click`（引导达成）。

### 4.5 常驻帮助入口（拉动式，替代 L3）

在页面右上角（返回按钮同级，标题右侧）常驻 `?` 图标，点击打开半屏说明面板：

| 面板结构 | 内容 |
| --- | --- |
| 三步上手 | ①选股票 ②选策略风格 / 用智能量化 ③点立即回测看模拟结果，每步一行文案 + 一张页面局部示意图 |
| 名词解释 | 复用附录 C 全量词条，支持搜索 |
| 常见问题 | 回测会真实下单吗？收益能拿到吗？为什么两个区块收益差很多？智能量化要多久？ |
| 风险提示 | 引用页面底部同源免责声明全文 |

面板可滚动、可随时下滑关闭，不含「下一步」流程，不做进度绑定。**用户主动打开的内容允许比自动引导详细得多**——这是本方案承接「需要强引导的少数用户」的唯一出口。

### 5.2 L0 常驻自解释

| 编号 | 位置 | 形态 | 文案 |
| --- | --- | --- | --- |
| D-L0-1 | 「当前持仓（模拟）」Tab 下方（**必做，优先级最高**） | 行内浅色说明 1~2 行 | 「持仓盈亏只算还在持有的标的；上方策略收益还包含已卖出的交易，两者可能一正一负」 |
| D-L0-2 | 「今日收益」为 `--` 时 | 值旁 `?` → 点释气泡 | 「非交易时段或当日尚未结算时不显示」 |

## 6. 频控与编排

### 6.1 单页规则

1. 同一页面同一次会话内：**最多 1 条 L1 + 最多 1 个 L2**，且**不同屏共存**；
2. 两条引导之间最小间隔 ≥ 3s；前一条未消失时后一条排队，队列长度 1，超时未排上即丢弃（不补偿、不顺延到下次）；
3. 页面内任何 L1 / L2 每个 `guide_id` **终身仅展示 1 次**（`shown_count` 达 1 即永久置灰），不做「N 次未完成则重复提醒」。

### 6.2 会话规则

1. 单次 App 会话（冷启动到退到后台超过 30 分钟为一次会话）内，本模块全局自动引导 ≤ **2 条**；
2. 同一自然日内本模块自动引导 ≤ **3 条**；
3. 用户在会话内已完成关键动作（完成回测 / 复制因子）后，该会话不再出任何自动引导。

### 6.3 跨页协同

从「个股量化」点「立即回测」跳到「策略详情」是最高频路径，两页引导会连续触发。规则：

1. 若本会话已在个股量化页展示过 L1，则策略详情页的 `G-D-L1-01` **本次不展示**，顺延到下一次会话（但 D-L0-1 等 L0 说明不受影响，始终展示）；
2. `G-Q-L2-01` 与 `G-D-L2-01` 不在同一会话内出现；
3. 通过「复制策略选股因子」返回个股量化页时，视为用户已理解闭环，`G-Q-L2-01` 直接置为已完成，不再展示。

### 6.4 负反馈熔断

| 触发条件 | 熔断范围 | 时长 |
| --- | --- | --- |
| 某条引导被用户点 `×` 主动关闭 1 次 | 该 `guide_id` | 永久 |
| 本模块累计 2 条引导被主动关闭 | 全模块 L1 / L2 自动引导 | 30 天 |
| 用户在设置中关闭「功能引导提示」 | 全模块 L1 / L2 自动引导 | 永久（L0 与帮助入口保留） |
| 引导曝光后 2s 内用户返回上一页，连续 2 次 | 该 `guide_id` | 永久（视为打扰信号） |

熔断只关自动引导，**永不关闭 L0 与帮助入口**——这是「可重看」原则的底线。

### 6.5 展示决策流程

```
进入页面 / 目标元素滚入视口
        │
        ├─ 引导配置拉取成功？──否──→ 静默跳过（记 guide_suppressed: config_fail）
        │  是
        ├─ is_novice == true？────否──→ 静默跳过（记 suppressed: not_novice）
        │  是
        ├─ 命中熔断 / 设置关闭？──是──→ 静默跳过（记 suppressed: fused）
        │  否
        ├─ 首屏数据加载成功且无其他浮层？─否─→ 静默跳过（记 suppressed: page_busy）
        │  是
        ├─ 会话/日频控有余额？────否──→ 静默跳过（记 suppressed: freq_cap）
        │  是
        ├─ 该 guide_id 已展示过？──是──→ 静默跳过（记 suppressed: already_shown）
        │  否
        ├─ 该引导的业务触发条件满足？（停留时长 / 滚动位置 / 元素可见性 / 未选股票 …）
        │       │否 → 继续监听，页面退出即放弃
        │       │是
        │       ↓
        │  屏幕上已有引导？──是──→ 入队（长度 1），前者消失后延迟 3s 再判一次
        │       │否
        │       ↓
        │  按 priority 升序取一条 → 展示（淡入 200ms）→ 埋 guide_impression
        │       ↓
        │  等待消失条件（超时 / 滚动 / 点击 / 关闭）→ 淡出 200ms
        │       ↓
        │  写入 shown_count / dismissed / completed → 同步服务端
```

### 6.6 状态存储与跨端同步

| 字段 | 说明 |
| --- | --- |
| `guide_id` | 引导唯一标识 |
| `shown_count` | 已展示次数（上限 1） |
| `last_shown_at` | 最近展示时间戳 |
| `dismissed` | 是否被主动关闭 |
| `completed` | 是否达成（点了引导指向的目标） |
| `fused_until` | 模块级熔断到期时间 |

写入策略：**本地先写、异步上报服务端**，登录后以服务端为准做一次合并（取「更保守」的一侧——任一端标记已展示 / 已关闭即视为已展示 / 已关闭）。目的是保证换设备、重装后不重复打扰；宁可漏教，不可重复教。

## 7. 视觉与交互规范

### 7.1 L1 顶部提示条

| 项 | 规范 |
| --- | --- |
| 高度 | 36pt（单行），文案超长不换行、不滚动，改用更短文案 |
| 位置 | 导航栏正下方，**挤压页面布局而非悬浮覆盖**（避免遮挡首个卡片） |
| 背景 | 主色 4% 浅底，无阴影、无边框 |
| 文字 | 13pt / 常规字重 / 次级文字色，不加粗、不用感叹号 |
| 右侧 | 12pt `×`，点击热区 ≥ 44×44pt |
| 动效 | 淡入 + 高度展开 200ms，收起同参数反向；低端机（见 7.5）直接无动画显隐 |

### 7.2 气泡（L1 元素气泡 / L2 聚焦气泡 / L0 点释气泡）

| 项 | 规范 |
| --- | --- |
| 最大宽度 | 屏宽 - 48pt，最多 2 行 |
| 箭头 | 8pt，指向目标元素中心，靠边时自动切换上 / 下 / 左 / 右并做边界收敛 |
| 背景 | 深色 90% 不透明（L1/L2）；L0 点释用浅底卡片以区分「解释」与「引导」 |
| 关闭 | L1/L2 点任意处即关；L0 点释点外部区域关，可含「了解更多」跳帮助面板 |
| 层级 | 低于系统弹窗、Toast、半屏；高于页面内容 |
| 事件 | **气泡与描边区域均不拦截点击**，事件透传至下层元素 |

### 7.3 L2 局部聚焦（关键差异点）

- **不加全屏遮罩**，不做背景变暗、不做挖孔；
- 目标元素处理：1pt 主色描边 + 圆角与原元素一致 + 阴影抬升 2pt；可选一次性 600ms 呼吸，**不循环**；
- 点击目标元素 → 气泡立即消失 + 原功能正常执行 + 记 `completed = true`；
- 页面滚动导致目标元素可见面积 < 50% → 气泡立即消失（不跟随、不吸附）。

### 7.4 术语点释（L0）

- 可点释术语统一使用 **1pt 虚线下划线**（不用蓝色、不用问号后缀，避免页面被 `?` 铺满）；区块级说明才用 `?` 图标；
- 词条内容 ≤ 40 字，必须包含「口径」与「怎么看」两部分，禁止只给公式；
- 词条库由服务端统一下发（附录 C），支持不发版更新与灰度；
- 点击埋 `term_tip_click`，用于反向发现「用户真正看不懂什么」，作为 V1.2 的优化输入。

### 7.5 动效与性能降级

以下情况**降级为无动效直接显隐**（不取消引导，只去动画）：系统「减弱动态效果」开启、设备内存 ≤ 3G、当前页帧率近 1s 均值 < 45fps、正在滚动惯性中。

### 7.6 无障碍

- 提示条与气泡文案必须可被读屏朗读，出现时发送 `announceForAccessibility`；
- 引导不改变原有焦点顺序；`×` 与 `?` 均需 `accessibilityLabel`；
- 文字随系统字号缩放，最大档下允许提示条升为 2 行（上限 56pt），仍超长则本条不展示。

## 8. 文案规范与合规

### 8.1 文案硬约束

| 项 | 规范 |
| --- | --- |
| L1 文案 | ≤ 20 字，单句，不用感叹号 |
| L2 文案 | ≤ 24 字，必须包含「动作 + 结果」，例：「复制后到自定义里改参数，不会自动交易」 |
| L0 点释 | ≤ 40 字 |
| 人称 | 用「你」，不用「您」「亲」；不用「小助手」「带你」等拟人化表达 |
| 结构 | 不写「点击此处」「如图所示」；直接说结果 |

### 8.2 禁用词（合规红线）

引导文案一律不得出现：推荐、精选、必看、稳赚、翻倍、抓住、跟买、跟单、买入、卖出、加仓、建议、预期收益、目标价、稳健收益、大概率、无风险，以及任何对未来收益的定量或定性预测。

### 8.3 合规必备

1. 所有出现收益数字的引导与解释文案，必须同时出现「模拟」或「历史」字样；
2. `G-D-L1-01`「以下均为历史模拟结果，不代表未来收益」为**合规必备项**，不参与频控裁剪、不参与 A/B 实验的对照组剔除（对照组同样展示，仅作为 L0 常驻文案存在）；
3. 底部免责声明（现状已有）保持常驻、不折叠、不因引导上线而缩短；
4. 「+」加自选动作的提示必须明确「不产生任何交易」；
5. 全量文案（含附录 B、C）上线前过合规评审，评审记录归档。

## 9. 非功能需求

### 9.1 配置下发

- 新增 `GET /quant/guide/config`，返回引导清单（`guide_id`、`level`、`priority`、`trigger`、`copy`、`enabled`、`max_show`）与术语词条库；
- 支持按版本号、平台、灰度分组、用户分层下发；支持**单条开关**与文案热更新（不发版）；
- 客户端强制「配置缺失即不展示」，禁止内置兜底引导；
- 响应可缓存 24h，随首屏接口并行请求，不阻塞渲染。

### 9.2 性能

| 指标 | 要求 |
| --- | --- |
| 引导判定耗时 | 单次 ≤ 5ms，在主线程空闲帧执行 |
| 首屏影响 | 引导模块不得延后首屏渲染，TTI 增量 ≤ 10ms |
| 内存 | 引导层常驻内存增量 ≤ 1MB |
| 包体 | 增量 ≤ 200KB（示意图使用矢量或在线图，不打入包体） |

### 9.3 埋点

| 事件 | 关键字段 |
| --- | --- |
| `guide_impression` | guide_id, level, page, trigger, is_novice, session_id |
| `guide_dismiss` | guide_id, dismiss_type（manual / timeout / scroll / action / page_leave）, duration_ms |
| `guide_target_click` | guide_id（引导达成，与 dismiss 可同时上报） |
| `guide_suppressed` | guide_id, reason（config_fail / not_novice / fused / page_busy / freq_cap / already_shown / element_invisible） |
| `guide_help_click` | page（帮助入口点击） |
| `guide_help_view` | page, section, duration_ms |
| `term_tip_click` | term_id, page, position |
| `guide_setting_change` | enabled（设置项开关） |

`guide_suppressed` 是本方案最重要的一条埋点：弱引导的主要风险是「该出没出」，只有把跳过原因记全，才能判断转化未提升是文案无效还是根本没曝光。

### 9.4 灰度与实验

- 分组：对照组（仅 L0 + 帮助入口）/ 实验组（L0 + L1 + L2 + 帮助入口），各 50%，仅对 `is_novice` 用户分流；
- 灰度节奏：1% → 5% → 20% → 50%，每档观察 ≥ 3 个交易日，重点看 1.2 中的**打扰度指标**；
- 熔断阈值：任一档出现「L1 手动关闭率 > 25%」或「引导曝光后 3s 内退出率相对对照组 +1.5 pp」，立即通过配置关闭对应引导并复盘；
- L0 项（尤其 D-L0-1）**不做 A/B，全量直发**——口径说明缺失属于线上问题，不做实验。

## 10. 异常与边界

| 场景 | 处理 |
| --- | --- |
| 首屏接口失败 / 超时 / 空数据 | 不展示任何自动引导；L0 中依赖数据的项（如今日收益空值说明）随数据恢复再出 |
| 引导目标元素被裁切、被键盘遮挡、不在视口 | 不展示，记 `suppressed: element_invisible`，本次不补 |
| 列表异步回流导致元素位移 | 气泡不跟随，直接消失 |
| 页面切后台 / 息屏 / 来电 | 立即消失，`shown_count` 计入（不重复补偿） |
| 用户快速返回上一页 | 引导随页面销毁，`dismiss_type = page_leave` |
| 分屏 / 折叠屏展开 / 横竖屏切换 | 布局变化即消失，不重排 |
| 深色模式 | 提示条与气泡需提供深色配色，对比度 ≥ 4.5:1 |
| 多语言 / 超长文案 | 超出行数限制则本条不展示（不截断、不省略号） |
| 引导与 App 内活动弹窗冲突 | 活动弹窗优先，引导本次跳过 |
| 老用户升级到新版本 | 依据 3.2 直接判为非新手，不因「首次进入新版本」而重新触发 |

## 附录 C：术语点释词条表

| term_id | 术语 | 释义（≤ 40 字） |
| --- | --- | --- |
| `T-BACKTEST` | 回测 | 用历史行情把策略规则重跑一遍，看当时会有什么结果；不是真实交易，也不预测未来 |
| `T-BACKTEST-RET` | 回测收益（近 7 天模拟） | 该策略在过去 7 个交易日按规则模拟买卖的累计收益，未扣手续费与滑点 |
| `T-STYLE` | 策略风格 | 按持仓集中度与换手快慢分类：进取型波动更大，稳健型波动更小，与收益高低无关 |
| `T-STRATEGY-RET` | 策略收益（模拟） | 所选区间内策略模拟净值的累计涨幅，包含已卖出交易的盈亏 |
| `T-TODAY-RET` | 今日收益 | 当日策略模拟净值的涨幅，非交易时段或未结算时显示为「--」 |
| `T-WINRATE` | 平均胜率 | 模拟交易中盈利笔数占总笔数的比例，只看输赢次数，不看赚多少 |
| `T-PLRATIO` | 盈亏比 | 平均每笔盈利金额 ÷ 平均每笔亏损金额，大于 1 表示赚的比亏的多 |
| `T-DRAWDOWN` | 最大回撤 | 区间内净值从最高点回落到最低点的最大幅度，反映最难受的时候亏多少 |
| `T-POSITION` | 当前持仓（模拟） | 策略当前按规则应持有的标的，为模拟结果，与你的真实账户无关 |
| `T-TRADES` | 交易明细（模拟） | 策略按规则模拟产生的买卖记录，含时间、价格与数量 |
| `T-COST` | 成本价 | 模拟买入的均价，不含手续费与税费 |
| `T-TURNOVER` | 换手率 | 当日成交股数占流通股的比例，越高说明买卖越活跃 |
| `T-UPDAYS` | 连涨天数 | 连续收盘上涨的交易日数量 |
| `T-VOLRATIO` | 日量比 | 当日成交量与近期平均成交量的比值，大于 1 表示放量 |
| `T-FACTOR` | 选股因子 | 策略筛股用的条件与取值范围，可复制到「自定义」后自行修改 |
| `T-BENCHMARK` | 沪深 300 | 用作对比的市场基准指数，看策略是跑赢还是跑输大盘 |
