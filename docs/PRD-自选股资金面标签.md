## 1. 背景与目标

### 1.1 背景

自选股列表是行情类产品打开频次最高的页面，但当前列表只呈现「名称 / 代码 / 现价 / 涨跌幅」，信息密度低且同质化：

- 用户看到涨跌幅后，无法判断「这个涨跌背后是谁在买卖」，需要逐个点进个股详情页翻资金流向、龙虎榜、北向持股等多个 Tab；
- 资金面数据（主力净流入、龙虎榜机构席位、陆股通持股、融资余额、大宗交易）本身已在 App 内存在，但埋得很深，日均使用率低；
- 自选股页缺少「值得点进去看一眼」的信号，页面停留短、向个股详情页的转化率低。

### 1.2 目标

在自选股列表的每只个股上，用一个短标签把该股当前最值得关注的资金面信号前置到列表层，让用户「不点进去也知道发生了什么，想深看一键直达」。

| 类型 | 目标 | 首期衡量指标 |
| --- | --- | --- |
| 业务目标 | 提升自选股页向个股详情页的转化 | 自选股页 → 个股详情页点击率相对对照组 **+5%** 以上 |
| 业务目标 | 提升资金流向类功能的渗透 | 「个股详情页 - 资金流向」Tab 日活渗透率相对提升 **+15%** |
| 用户目标 | 降低获取资金面信息的成本 | 标签曝光点击率（CTR）≥ **3%**；标签点击后落地页停留时长 ≥ 20s |
| 体验目标 | 不打扰、不刷屏、不误导 | 标签功能主动关闭率 ≤ **1%**；标签「不感兴趣」负反馈率 ≤ **0.5%** |
| 数据质量 | 标签口径与详情页数据一致 | 人工抽检一致率 ≥ **99.5%**；标签计算延迟 P99 ≤ 30s（实时类） |

### 1.3 非目标（本期明确不做）

1. 不做买卖点提示、不做评分排序、不做涨跌预测，标签只描述**已发生的客观资金事实**；
2. 不做港股 / 美股 / 基金 / 债券 / ETF（V1.1 起评估 ETF 与港股通）；
3. 不做标签的个性化推荐排序（V2.0 评估）；
4. 不改造自选股列表的排序逻辑，标签不参与排序。

## 2. 名词与数据口径定义

后续所有计算规则均基于本节口径，禁止各端各自实现。

| 术语 | 定义 |
| --- | --- |
| 主力资金 | 基于 Level-2 逐笔成交，按单笔成交金额分档：超大单（≥ 100 万元）+ 大单（20 万 ~ 100 万元）。买卖方向按主动性判定：以卖方挂单价成交计为「主动买入」，以买方挂单价成交计为「主动卖出」 |
| 主力净流入额 `NetIn` | 主力资金主动买入额 − 主动卖出额，单位：元。为负时称「主力净流出」 |
| 主力净流入占比 `R` | `R = NetIn / 当日总成交额`，取值区间约 (−1, 1) |
| 历史分位 `Q` | 当日 `NetIn` 在该股**近 60 个交易日** `NetIn` 序列中的分位数（0% ~ 100%） |
| 市值分层 | 按**流通市值**分三档：大盘 ≥ 500 亿；中盘 100 亿 ≤ 市值 < 500 亿；小盘 < 100 亿 |
| 绝对额阈值 `T` | 与市值分层挂钩的资金绝对额门槛：大盘 `T = 2 亿元`；中盘 `T = 8000 万元`；小盘 `T = 3000 万元` |
| 量比 `VR` | 当日单位时间成交量 / 过去 5 个交易日同一时段的平均单位时间成交量 |
| 机构席位净买入 | 交易所龙虎榜中「机构专用」席位买入额合计 − 卖出额合计 |
| 北向持股比例 | 陆股通（沪股通 + 深股通）持股数量 / 该股流通股本，单位：百分点（pp） |
| 交易日 / T 日 | 沪深交易所交易日历；T+1 指下一个交易日 |
| 信号强度分 `S` | 用于同优先级排序的归一化强度，见 4.3 |

> **阈值双门槛设计说明**：资金绝对额在不同市值个股间不可比（小盘股 3000 万元即为大单流入，大盘股 3000 万元可忽略）。因此所有资金额类规则统一采用「**相对占比 `R` 必须达标** + （**绝对额达标** 或 **个股历史分位达标**）」的复合条件，兼顾横向可比与个股自身的异常度。

## 3. 标签名称

### 3.1 标签总表

首期共 12 个标签，分为「资金流出（风险侧）」「资金流入（机会侧）」「中性」三类。`tag_id` 为服务端与客户端约定的稳定标识，文案变更不改 `tag_id`。

| tag_id | 标签名称（展示文案） | 类别 | 视觉色板 | 合规备选文案 | 一句话含义 |
| --- | --- | --- | --- | --- | --- |
| `INST_SELL` | 机构净卖出 | 流出 | 绿底绿字（跌色系） | — | 龙虎榜机构专用席位大额净卖出 |
| `MAIN_OUTFLOW` | 主力大额流出 | 流出 | 绿底绿字 | — | 当日主力资金大额净流出 |
| `MAIN_OUT_STREAK` | 主力{N}日流出 | 流出 | 绿底绿字 | — | 主力资金连续多日净流出 |
| `NORTH_REDUCE` | 北向{N}日减仓 | 流出 | 绿底绿字 | — | 陆股通连续多日减持 |
| `INST_BUY` | 机构净买入 | 流入 | 红底红字（涨色系） | — | 龙虎榜机构专用席位大额净买入 |
| `MAIN_INFLOW` | 主力大额流入 | 流入 | 红底红字 | 主力抢筹 | 当日主力资金大额净流入 |

| `MAIN_IN_STREAK` | 主力{N}日流入 | 流入 | 红底红字 | — | 主力资金连续多日净流入 |
| `NORTH_ADD` | 北向{N}日加仓 | 流入 | 红底红字 | — | 陆股通连续多日增持 |
| `MARGIN_UP` | 融资余额大增 | 流入 | 橙底橙字 | 杠杆资金加仓 | 融资余额短期显著增长 |
| `BLOCK_PREMIUM` | 大宗溢价成交 | 流入 | 橙底橙字 | — | 大宗交易以溢价成交且金额显著 |
| `FUND_DIVERGE` | 资金分歧 | 中性 | 灰底灰字 | — | 巨量换手但主力资金多空基本对冲 |

### 3.2 文案规范

1. **长度**：展示文案统一控制在 **6 个字符以内**（数字计 1 个字符）。列表宽度有限，连续型标签采用紧凑写法「主力5日流入」「北向3日加仓」，其中 `N` 为实际连续天数，最大展示 `9`，超过 9 天固定显示 `9日+`（如「主力9日+流入」，此为唯一允许超过 6 字的例外）。
2. **禁用词**：不得出现「买入 / 建议 / 必涨 / 抄底 / 逃顶 / 龙头 / 牛股」等含投资建议或结果承诺的表述。「抢筹」类文案需经合规复核后方可启用，默认使用中性备选文案（表中「标签名称」列为默认上线文案）。
3. **色彩语义**：红＝资金流入，绿＝资金流出，橙＝杠杆/场外资金类，灰＝中性。需同时提供**涨绿跌红**配色下的镜像方案，并跟随 App 全局涨跌色设置。
4. **多语言**：首期仅简体中文；文案走服务端下发，客户端不硬编码，便于合规调整与 A/B 文案实验。

### 3.3 展示位置与交互

| 项 | 规则 |
| --- | --- |
| 位置 | 自选股列表行内，股票名称右侧，紧邻名称；标签超出行宽时名称优先，标签整体隐藏（不截断标签文字） |
| 数量 | **同一时间同一只股票至多显示 1 个标签**（见第 4 节优先级） |
| 样式 | 圆角 4px、字号 10pt、上下内边距 2px、左右内边距 4px、透明度 12% 的同色底 |
| 点击 | 点击标签跳转「个股详情页 - 资金流向」Tab，并按标签类型锚定到对应模块（龙虎榜类锚定龙虎榜模块、北向类锚定陆股通持股模块），带 `tag_id` 与 `source=watchlist_tag` 参数 |
| 说明入口 | 落地页顶部提供「标签说明」入口，展示该标签的完整计算口径、数据来源、更新时间与免责声明 |
| 负反馈 | 列表行左滑菜单增加「不再显示此类标签」，点击后该 `tag_id` 对用户级屏蔽 30 天；设置页 → 行情设置 → 「资金面标签」总开关，默认开启 |
| 空态 | 无标签时不占位、不留白，列表行高与现状完全一致 |

## 4. 标签优先级

### 4.1 优先级设计原则

同一时间只允许显示一个标签，因此优先级必须唯一可判定。排序依据以下四条原则，从上到下依次生效：

1. **风险优先于机会**：自选股多为已持仓/重点关注标的，资金流出类信号对用户的决策价值高于流入类，避免只呈现利好造成单边引导；
2. **权威披露优于推算**：交易所披露的龙虎榜、陆股通持股、融资余额、大宗交易为确定性数据，优先于基于 Level-2 逐笔推算的主力资金；
3. **稀缺性/信息增量优先**：全市场覆盖率越低的信号信息量越大（龙虎榜机构席位单日仅数十只个股），优先级越高；
4. **具体优于笼统**：约束条件更强、指向更明确的标签优先（如「尾盘资金流入」是「主力大额流入」的子集，前者优先）。

### 4.2 优先级序列

`P1` 为最高优先级。同一股票同一时刻命中多个标签时，取 `P` 值最小者展示，其余标签仅在落地页呈现。

| 优先级 | tag_id | 标签名称 | 类别 | 命中原则 | 预估全市场日覆盖率 |
| --- | --- | --- | --- | --- | --- |
| P1 | `INST_SELL` | 机构净卖出 | 流出 | 风险 + 权威 + 稀缺 | ~0.3% |
| P2 | `MAIN_OUTFLOW` | 主力大额流出 | 流出 | 风险 + 实时 | ~2.5% |
| P3 | `MAIN_OUT_STREAK` | 主力{N}日流出 | 流出 | 风险 + 趋势 | ~1.5% |
| P4 | `NORTH_REDUCE` | 北向{N}日减仓 | 流出 | 风险 + 权威 | ~1.0% |
| P5 | `INST_BUY` | 机构净买入 | 流入 | 权威 + 稀缺 | ~0.4% |
| P6 | `TAIL_INFLOW` | 尾盘资金流入 | 流入 | 具体优于笼统 | ~1.0% |
| P7 | `MAIN_INFLOW` | 主力大额流入 | 流入 | 实时 + 强度 | ~2.5% |
| P8 | `MAIN_IN_STREAK` | 主力{N}日流入 | 流入 | 趋势 | ~1.5% |
| P9 | `NORTH_ADD` | 北向{N}日加仓 | 流入 | 权威 | ~1.2% |
| P10 | `MARGIN_UP` | 融资余额大增 | 流入 | 场外杠杆 | ~1.0% |
| P11 | `BLOCK_PREMIUM` | 大宗溢价成交 | 流入 | 事件型、低频 | ~0.2% |
| P12 | `FUND_DIVERGE` | 资金分歧 | 中性 | 兜底、信息量最低 | ~1.5% |

> 表中覆盖率为**各标签独立命中率**的预估值，合计约 14.6%；由于一只个股常同时命中多个标签而只展示 1 个，去重后的「带标签个股占比」约 10%。该组数据须在上线前以近 6 个月全市场数据回溯校准（见 7.2）。目标：**全市场单日带标签个股占比 10% ± 3%**，任一单标签独立命中率 ≤ 3%。

### 4.3 同优先级与冲突处理

1. **同优先级**（本期各标签 `P` 值唯一，该规则用于后续新增标签）按**信号强度分 `S` 降序**取第一个。`S` 为该标签核心指标的分位数（0~100）：个股连续性/占比类指标取该股近 60 个交易日分位，事件披露类指标取全市场近 60 个交易日分位，各标签的取法见 5.3；
2. `S` 相同则取**信号生成时间更晚**者；仍相同则按 `tag_id` 字典序，保证结果稳定可复现；
3. **互斥约束**：同一股票不允许同时下发流入类与流出类标签。若因数据源时点差异出现矛盾（如 T+1 的 `INST_BUY` 与当日实时 `MAIN_OUTFLOW` 同时命中），按优先级取 `MAIN_OUTFLOW`，并在落地页同时展示两条信息，不在列表层做合并；
4. **防抖动**：标签一经在列表展示，**最少保持 30 分钟**不被同类或更低优先级标签替换；仅当出现优先级 ≤ P4 的流出类标签时可立即覆盖（风险信息不延迟）；
5. **单股每日切换上限 3 次**，达到上限后当日锁定最后一次结果，直至收盘。

### 4.4 展示决策流程

```
输入：股票 code、当前时间 now、用户 uid

1. 若功能总开关关闭 → 不展示
2. 若 code 命中排除名单（停牌 / 退市整理期 / 上市 ≤ 10 个交易日 / 非 A 股）→ 不展示
3. 取该 code 当前所有「有效期内」的候选标签集合 C
4. C 中剔除该 uid 已负反馈屏蔽（30 天内）的 tag_id
5. C 为空 → 不展示
6. 按 (P 升序, S 降序, 生成时间降序, tag_id 升序) 排序，取 top1 = tag
7. 若该 code 上一次展示的标签 last 仍在有效期内，且 now - last.show_ts < 30min，
   且 tag.P >= last.P，且 tag 非 P1~P4 流出类 → 继续展示 last
8. 若该 code 当日已切换 3 次 → 继续展示 last
9. 展示 tag
```

用户级总量控制（客户端渲染层执行，服务端下发全量）：单个用户自选股列表中带标签的股票数上限为 `min(5, ceil(20% × 自选股总数))`，超出时按 `(P 升序, S 降序)` 截断，保证列表不刷屏。

## 5. 标签计算规则

### 5.1 全局前置条件（所有标签共同适用）

同时满足以下条件的个股才进入标签计算：

1. 标的类型为 A 股个股，且当日为交易日；
2. 当日未停牌、非退市整理期、非上市首日起 10 个交易日内的新股；
3. 当日成交额 ≥ 5000 万元（成交额过低时资金流指标噪声大）；
4. 数据源在有效期内完成回填，无数据缺失标记（见 8.2 降级策略）。

### 5.2 分档阈值表

| 市值分层 | 流通市值 | 绝对额阈值 `T` |
| --- | --- | --- |
| 大盘 | ≥ 500 亿元 | 2 亿元 |
| 中盘 | 100 亿 ~ 500 亿元 | 8000 万元 |
| 小盘 | < 100 亿元 | 3000 万元 |

阈值需配置化（后台可调，无需发版），并支持按市值分层分别调整。

### 5.3 各标签计算规则

#### P1 `INST_SELL` 机构净卖出

- **数据源**：交易所龙虎榜每日公开信息（沪深两市「公开信息」文件）
- **规则**：T 日该股登上龙虎榜，且机构专用席位净买入 `< 0`，且 `|机构席位净买入| ≥ max(3000 万元, 当日成交额 × 3%)`
- **强度分 `S`**：`|机构席位净卖出| / 当日成交额` 的近 60 交易日全市场分位
- **文案**：`机构净卖出`

#### P2 `MAIN_OUTFLOW` 主力大额流出

- **数据源**：Level-2 逐笔成交
- **规则**：`R ≤ −5%` 且（`NetIn ≤ −T` 或 `Q ≤ 10%`）
- **强度分 `S`**：`|R|` 的近 60 交易日个股分位
- **文案**：`主力大额流出`

#### P3 `MAIN_OUT_STREAK` 主力{N}日流出

- **数据源**：Level-2 逐笔成交日频汇总
- **规则**：连续 `N ≥ 3` 个交易日 `NetIn < 0`，且区间累计净流出 `≥ 1.5 × T`。`N` 取实际连续天数（最大计 9）
- **强度分 `S`**：`区间累计净流出 / (N × T)` 归一化后的分位
- **文案**：`主力{N}日流出`

#### P4 `NORTH_REDUCE` 北向{N}日减仓

- **数据源**：沪深港通持股明细（陆股通持股数量、持股占流通股比）
- **规则**：仅限沪深股通标的。连续 `N ≥ 3` 个交易日陆股通持股数量下降，且区间累计减持占流通股 `≥ 0.3 pp`，且区间累计减持市值 `≥ 5000 万元`
- **强度分 `S`**：区间累计减持 pp 的近 60 交易日全市场分位
- **文案**：`北向{N}日减仓`

#### P5 `INST_BUY` 机构净买入

- **数据源**：交易所龙虎榜每日公开信息
- **规则**：T 日该股登上龙虎榜，且机构专用席位净买入 `> 0`，且 `机构席位净买入 ≥ max(3000 万元, 当日成交额 × 3%)`
- **强度分 `S`**：`机构席位净买入 / 当日成交额` 的近 60 交易日全市场分位
- **文案**：`机构净买入`

#### P6 `TAIL_INFLOW` 尾盘资金流入

- **数据源**：Level-2 逐笔成交（分时段汇总）
- **规则**：同时满足
  1. 14:30 ~ 15:00 区间主力净流入 `> 0`，且 `≥ 全天主力净流入 × 50%`；
  2. 全天主力净流入 `≥ 0.6 × T`；
  3. 全天 `R ≥ 3%`
- **盘中口径**：14:30 ~ 15:00 未走完时，「尾盘区间」按 `14:30 ~ 当前时刻` 计算，「全天」按 `09:30 ~ 当前时刻` 计算；15:00 后按完整区间定稿
- **强度分 `S`**：`尾盘区间净流入 / 全天成交额` 的近 60 交易日个股分位
- **文案**：`尾盘资金流入`

#### P7 `MAIN_INFLOW` 主力大额流入

- **数据源**：Level-2 逐笔成交
- **规则**：`R ≥ 5%` 且（`NetIn ≥ T` 或 `Q ≥ 90%`）
- **强度分 `S`**：`R` 的近 60 交易日个股分位
- **文案**：`主力大额流入`

#### P8 `MAIN_IN_STREAK` 主力{N}日流入

- **数据源**：Level-2 逐笔成交日频汇总
- **规则**：连续 `N ≥ 3` 个交易日 `NetIn > 0`，且区间累计净流入 `≥ 1.5 × T`
- **强度分 `S`**：`区间累计净流入 / (N × T)` 归一化后的分位
- **文案**：`主力{N}日流入`

#### P9 `NORTH_ADD` 北向{N}日加仓

- **数据源**：沪深港通持股明细
- **规则**：仅限沪深股通标的。连续 `N ≥ 3` 个交易日陆股通持股数量上升，且区间累计增持占流通股 `≥ 0.3 pp`，且区间累计增持市值 `≥ 5000 万元`
- **强度分 `S`**：区间累计增持 pp 的近 60 交易日全市场分位
- **文案**：`北向{N}日加仓`

#### P10 `MARGIN_UP` 融资余额大增

- **数据源**：交易所融资融券交易明细
- **规则**：仅限两融标的。T 日融资余额较 T−5 日增幅 `≥ 10%`，且最近 2 个交易日融资余额均环比增长，且 T 日融资余额 `≥ 1 亿元`
- **强度分 `S`**：5 日融资余额增幅的近 60 交易日全市场分位
- **文案**：`融资余额大增`

#### P11 `BLOCK_PREMIUM` 大宗溢价成交

- **数据源**：大宗交易成交公告
- **规则**：T 日大宗交易成交金额合计 `≥ max(5000 万元, 流通市值 × 0.5%)`，且成交均价 `≥ T 日收盘价 × 1.02`
- **强度分 `S`**：`成交金额 / 流通市值` 的近 60 交易日全市场分位
- **文案**：`大宗溢价成交`

#### P12 `FUND_DIVERGE` 资金分歧

- **数据源**：Level-2 逐笔成交 + 行情快照
- **规则**：当日换手率 `≥ 近 60 交易日平均换手率 × 2`，且 `|R| < 1%`，且当日成交额 `≥ 1 亿元`
- **强度分 `S`**：换手率放大倍数的近 60 交易日个股分位
- **文案**：`资金分歧`

### 5.4 数据源汇总

| 数据源 | 用于标签 | 披露/可用时点 | 依赖方 |
| --- | --- | --- | --- |
| Level-2 逐笔成交 | `MAIN_INFLOW` `MAIN_OUTFLOW` `MAIN_*_STREAK` `TAIL_INFLOW` `FUND_DIVERGE` | 盘中实时（3 秒快照） | 行情网关 |
| 行情快照（成交额、换手率、流通市值） | 全部（前置条件与分层） | 盘中实时 | 行情网关 |
| 交易所龙虎榜公开信息 | `INST_BUY` `INST_SELL` | T 日约 18:00 后 | 数据平台 |
| 沪深港通持股明细 | `NORTH_ADD` `NORTH_REDUCE` | T 日约 20:00 后 | 数据平台 |
| 融资融券交易明细 | `MARGIN_UP` | T 日约 21:00 后 | 数据平台 |
| 大宗交易成交公告 | `BLOCK_PREMIUM` | T 日约 17:30 后 | 数据平台 |
| 交易日历 / 停牌退市名单 | 前置条件 | 每日 08:30 | 数据平台 |

## 6. 标签频率

「频率」分四层定义：**计算频率**（多久算一次）、**可展示时点与有效期**（什么时间段展示）、**展示频控**（同一信号多久提示一次）、**用户级频控**（一个用户一次看到多少）。

### 6.1 计算频率与有效期

| tag_id | 计算频率 | 计算时点 | 最早可展示 | 有效期截止 |
| --- | --- | --- | --- | --- |
| `MAIN_INFLOW` / `MAIN_OUTFLOW` / `FUND_DIVERGE` | 每 3 分钟一次（快照式，非逐笔触发） | 交易时段 09:30–11:30、13:00–15:00 | 当日 **09:45**（开盘 15 分钟内数据噪声大，不出标签） | T+1 日 09:15（次日开盘前清除） |
| `TAIL_INFLOW` | 每 3 分钟一次 | 仅 14:30–15:00 | 当日 **14:36** | T+1 日 09:15 |
| `MAIN_IN_STREAK` / `MAIN_OUT_STREAK` | 每日 1 次 | T 日 15:30 跑批 | T 日 **16:00** | T+1 日 15:00 |
| `BLOCK_PREMIUM` | 每日 1 次 | T 日 18:00 跑批 | T 日 **18:30** | T+1 日 15:00 |
| `INST_BUY` / `INST_SELL` | 每日 1 次 | T 日 18:30 跑批 | T 日 **19:00** | T+1 日 15:00 |
| `NORTH_ADD` / `NORTH_REDUCE` | 每日 1 次 | T 日 20:30 跑批 | T 日 **21:00** | T+1 日 15:00 |
| `MARGIN_UP` | 每日 1 次 | T 日 21:30 跑批 | T 日 **22:00** | T+1 日 15:00 |

补充说明：

1. **实时类为什么是 3 分钟**：主力净流入在分钟级会反复穿越阈值，若逐笔触发会导致标签闪烁。3 分钟快照 + 30 分钟最短保持（见 4.3）可将单股日均标签变化次数控制在 3 次以内；
2. **盘后与非交易时段**：15:00 收盘后至 T+1 日 09:15，列表展示当日/T 日的最终结论标签（此时标签视为「T 日收盘结论」）；T+1 日 09:15 起清空实时类，等待当日 09:45 重新产出。周末与节假日展示最近一个交易日的结论标签；
3. **T+1 类标签的双日窗口**：龙虎榜/北向/两融/大宗的数据在 T 日盘后才披露，因此展示窗口为「T 日盘后 ~ T+1 日收盘」，覆盖用户当晚复盘与次日盘中两个使用场景；
4. **失效即刻回收**：有效期到达、或个股当日盘中触发停牌、或数据源回滚修正后不再满足规则时，标签在下一个计算周期（≤ 3 分钟）内消失。

### 6.2 展示频控（防疲劳）

| 规则 | 说明 |
| --- | --- |
| 连续命中不重复计次 | 同一股票同一 `tag_id` 连续多日达标时，视为**同一次信号**，持续展示；不触发频控 |
| 再次触发间隔 | 同一股票同一 `tag_id` 信号中断后，需间隔 **≥ 1 个交易日**才可再次产出，避免同一天内反复出现/消失 |
| 单股最短保持 | 标签展示后最少保持 **30 分钟**（P1~P4 流出类可即时覆盖，见 4.3） |
| 单股每日切换上限 | **3 次**/交易日 |
| 用户负反馈 | 用户对某 `tag_id` 点击「不再显示此类标签」后，该 `tag_id` 对该用户屏蔽 **30 天** |

### 6.3 用户级频控

| 规则 | 说明 |
| --- | --- |
| 列表带标签个股上限 | `min(5, ceil(20% × 自选股总数))`；例：自选股 10 只 → 上限 2 只；自选股 50 只 → 上限 5 只 |
| 截断规则 | 超出上限时按 `(P 升序, S 降序)` 保留，其余不渲染 |
| 分组隔离 | 自选股分组切换时按当前分组内的股票重新计算上限 |
| 全局开关 | 设置页可一键关闭，关闭后不再请求标签接口 |

## 7. 非功能需求

### 7.1 性能与接口

| 项 | 要求 |
| --- | --- |
| 接口 | `GET /v1/watchlist/fund-tags?codes={code1,code2,...}`，单次最多 500 只 |
| 返回字段 | `code`、`tag_id`、`tag_name`、`tag_type`(inflow/outflow/neutral)、`priority`、`strength`、`generated_at`、`expire_at`、`jump_url` |
| 接口延迟 | P99 ≤ 200ms（500 只批量） |
| 计算延迟 | 实时类：数据到达 → 标签可查 P99 ≤ 30s；盘后类：数据披露 → 标签可查 ≤ 30min |
| 缓存 | 服务端结果缓存 TTL 3 分钟，与计算周期对齐；客户端内存缓存 3 分钟，随列表刷新更新 |
| 请求时机 | 自选股页进入、下拉刷新、以及页面可见时每 3 分钟轮询一次（与行情刷新合并请求，不额外增加请求次数） |

### 7.2 阈值校准与灰度

1. **回溯校准**：上线前用近 6 个月全市场数据跑一遍全部规则，输出每个标签的日均命中只数、覆盖率、同优先级冲突率、单股日均切换次数；若全市场覆盖率偏离 `10% ± 3%`，按 5.2 阈值表调整绝对额阈值与占比阈值后重跑；
2. **灰度节奏**：10% → 50% → 100%，每档观察至少 5 个交易日；对照组不展示标签，用于评估 1.2 节的转化指标；
3. **A/B 实验**：同步实验「默认文案 vs 合规备选文案」对 CTR 的影响；
4. **可回滚**：功能开关、单标签开关、阈值均为后台配置，可分标签下线，不依赖发版。

## 8. 异常与边界

### 8.1 业务边界

| 场景 | 处理 |
| --- | --- |
| 停牌 / 退市整理期 | 不展示任何标签；停牌前已展示的标签立即回收 |
| 上市 ≤ 10 个交易日的新股 | 不展示（历史分位与连续性指标不可用） |
| ST / *ST 个股 | 正常参与计算；流出类标签优先级不变（已由 P1~P4 保证风险前置） |
| 非沪深股通标的 | 不产出 `NORTH_*` 标签 |
| 非两融标的 | 不产出 `MARGIN_UP` 标签 |
| 北交所个股 | 参与计算，但因流动性差异，绝对额阈值单独配置一档（初始取小盘阈值的 30%，随回溯结果调整） |
| 港股 / 美股 / 基金 / ETF / 债券 | 本期不展示，接口返回空 |
| 一字板涨停 / 跌停（全天无有效换手） | 不产出实时资金类标签（成交额前置条件通常已过滤，需显式排除） |

### 8.2 数据异常与降级

| 异常 | 降级策略 |
| --- | --- |
| Level-2 数据中断 | 保留最后一次有效计算结果至有效期结束，标签说明页标注「数据更新于 HH:mm」；中断超过 30 分钟则回收实时类标签 |
| 龙虎榜/北向/两融数据延迟披露 | 延迟至数据到达后计算并展示，展示窗口相应后移，但不跨越 T+1 日 15:00 的有效期上限 |
| 数据源事后修正（如龙虎榜更正） | 下一个计算周期重算，标签可能消失或变更，允许且不做特殊提示 |
| 标签接口超时/失败 | 客户端静默降级为无标签，不弹错、不影响行情列表渲染；失败后 3 分钟内不重试 |
| 计算任务失败 | 报警至数据平台值班；当日该类标签全量不下发，优于下发错误标签 |

### 8.3 合规要求

1. 标签仅陈述已发生的客观资金统计事实，不构成投资建议；标签说明页与落地页均需展示免责声明；
2. 全部标签的计算口径需在「标签说明」中公开可查，口径变更需记录版本与生效日期；
3. 标签数据口径必须与个股详情页的资金流向/龙虎榜/陆股通模块**同源同口径**，不允许两处数据不一致；
4. 文案上线前需过合规评审，评审记录留档。

## 9. 验收用例（摘要）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-01 | 某小盘股当日 `NetIn = 4000 万`、`R = 8%`、成交额 5 亿 | 展示 `主力大额流入` |
| TC-02 | 同一股票同时命中 `MAIN_OUTFLOW`(P2) 与 `INST_BUY`(P5) | 列表仅展示 `主力大额流出`，落地页两条信息均可见 |
| TC-03 | 09:35 某股已达 `MAIN_INFLOW` 阈值 | 09:45 前不展示标签，09:45 起展示 |
| TC-04 | 某股 10:00 展示 `主力大额流入`，10:10 转为 `资金分歧` 条件 | 继续展示 `主力大额流入`（未满 30 分钟且新标签优先级更低） |
| TC-05 | 某股 10:00 展示 `主力大额流入`，10:10 命中 `MAIN_OUTFLOW` | 立即切换为 `主力大额流出`（P2 流出类可即时覆盖） |
| TC-06 | 用户自选股 10 只，其中 6 只命中标签 | 仅渲染优先级最高的 2 只（`min(5, ceil(20%×10)) = 2`） |
| TC-07 | 用户对 `资金分歧` 点击「不再显示此类标签」 | 30 天内该用户全部自选股不再出现 `资金分歧`；其他标签正常 |
| TC-08 | T 日 19:00 某股龙虎榜机构净买入 5000 万、成交额 8 亿 | T 日 19:00 起展示 `机构净买入`，T+1 日 15:00 后消失 |
| TC-09 | 某股 T+1 日 09:20 查看 | 实时类标签已清空，T+1 类标签（龙虎榜/北向等）仍展示 |
| TC-10 | 某股当日停牌 | 无任何标签，已展示标签在 3 分钟内回收 |
| TC-11 | 标签接口返回 500 | 列表正常渲染，无标签、无报错提示 |
| TC-12 | 用户关闭「资金面标签」总开关 | 列表无标签，且不再发起标签接口请求 |
| TC-13 | 涨跌色设置切换为「涨绿跌红」 | 流入类标签变绿色系、流出类变红色系 |
| TC-14 | 自选股名称过长导致行宽不足 | 名称完整展示，标签整体隐藏（不出现半个标签） |
